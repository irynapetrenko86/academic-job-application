# Academic Job Application Webpage

This repository contains a polished academic web page for a mathematics applicant seeking Postdoctoral or Instructor roles.

## Files

- `index.html` – homepage structure
- `styles.css` – visual design and responsive layout
- `script.js` – small script for footer year

## How to view locally

Open `index.html` in a browser, or serve the folder with a simple local web server:

```bash
python3 -m http.server 8000
```

Then visit: http://localhost:8000

## Notes

The design is intentionally professional, research-oriented, and suitable for mathematics academic applications. You can personalize the text, courses, publications, and contact details to match your CV.
